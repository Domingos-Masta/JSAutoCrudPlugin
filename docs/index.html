JSAutoCrud

Generate Spring Boot REST layers in seconds — powered by generic-auto-crud.

Download plugin View on GitHub

Installation

  1. Download the latest .zip from the releases page.
  2. Open IntelliJ IDEA → Settings/Preferences → Plugins.
  3. Click the gear icon → Install Plugin from Disk… and select the zip.
  4. Restart the IDE.

Your Spring Boot project must include the library:

<dependency>
    <groupId>io.github.isys-dcore</groupId>
    <artifactId>generic-auto-crud</artifactId>
    <version>0.7.5</version>
</dependency>

Features

SQL & MongoDBGenerate JPA or MongoDB CRUD layers from one wizard.
DTO supportDTO, mapper, DTO service and DTO controller generation.
Integration testsReady-to-extend test classes backed by the library.
Entity associationsDefine JPA relationships between SQL entities.
Creation modesFrom scratch, from an existing entity, or a single layer.
Modern UIA clean, step-by-step wizard with a context submenu.

Usage

Right-click the project (or any file) in the Project tool window, choose AutoCRUD Resource, then pick a creation mode.
